# Modern Life (Minecraft Mod)

Official repository for **Modern Life**, an advanced Minecraft mod built with **Architectury API** supporting both **Fabric** and **Forge** mod loaders.

- **CurseForge Page:** [Download Modern Life on CurseForge](https://www.curseforge.com/minecraft/mc-mods/modernlife)
- **Architecture:** Architectury API (Multi-loader: Fabric & Forge)
- **Status:** Active Development
- **Total Downloads:** 350+ Downloads

---

## About The Project
Modern Life enhances the Minecraft universe by introducing modern economy, banking systems, taxation mechanics, identity systems, and interactive blocks like ATMs and Cash Registers. Built using Architectury API, it maintains a unified cross-platform codebase for high maintainability and efficiency.

## Repository Structure
- `common/` - Core mod logic, registries, network packets, and cross-platform assets.
- `fabric/` - Fabric-specific entry points and mod integration.
- `forge/` - Forge-specific entry points and setup configurations.
